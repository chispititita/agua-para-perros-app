# Servicios Móviles JC — Comparador de móviles

Web estática (HTML + CSS + JavaScript, sin dependencias) para ayudar a elegir, comparar y comprar móviles.

## Cómo abrirla
Descomprime el ZIP y abre `index.html` con doble clic en cualquier navegador. Para publicarla, sube la carpeta completa a cualquier hosting (Netlify, GitHub Pages, Hostinger, etc.).

## Funciones
- **Asistente** de 4 pasos (presupuesto, prioridades, sistema, extras) con recomendaciones y % de afinidad.
- **Catálogo** de 27 móviles (2024-2025) con filtros: precio, marca, sistema, batería, RAM, carga inalámbrica, IP68, teleobjetivo, carga rápida, compacto, plegable, actualizaciones y favoritos. 8 criterios de orden.
- **Comparador** de hasta 4 móviles: gráfico radar, veredicto por categoría, tabla con el mejor dato resaltado, ocultar filas iguales, enlace compartible e impresión/PDF.
- **Ficha de cada móvil**: puntuaciones, pros/contras, "ideal para", especificaciones completas, **dónde comprar** (tienda oficial, Amazon, PcComponentes, MediaMarkt, El Corte Inglés, Fnac, Idealo, Google Shopping, Back Market y Wallapop), calculadora de financiación y **alternativas** (más barato, mejor cámara, más batería, otro sistema…).
- Búsqueda instantánea, favoritos guardados, modo claro/oscuro y diseño adaptado a móvil.

## Editar datos
Todos los móviles están en `js/data.js`. Para añadir uno, copia un bloque y cambia sus valores.
Los precios son de lanzamiento y orientativos; los enlaces llevan al precio real de cada tienda.
