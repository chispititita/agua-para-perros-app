Generar fotos de los móviles con OpenAI

Esta herramienta crea una foto de estudio realista de cada móvil. Usa el dibujo a escala de la web como referencia para que la IA respete la forma, las cámaras y el color de cada modelo.

Cómo se usa

  1. Crea una clave en platform.openai.com → API keys (necesitas saldo en tu cuenta).
  2. Pégala abajo, elige la calidad y pulsa Generar fotos. Tarda unos minutos.
  3. Revisa las fotos y pulsa Descargar ZIP.
  4. Descomprime ese ZIP dentro de la carpeta de la web (la que contiene index.html) y acepta reemplazar js/fotos.js. ¡Listo!

🔒 Tu clave solo se usa en este navegador para hablar directamente con OpenAI; no se guarda ni se envía a ningún otro sitio. No subas este archivo con tu clave escrita a ningún servidor.

Coste aproximado con gpt-image-1: unos 0,05 € por foto en calidad media y unos 0,20 € en alta (unos 1,5 € / 6 € las 31 fotos). Consulta los precios actuales en OpenAI.
