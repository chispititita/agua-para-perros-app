# Agua Para Perros — herramientas

- `agua-para-perros-app (1).html` — dashboard de la tienda.
- [`jarvis/`](jarvis/README.md) — **J.A.R.V.I.S.**, asistente personal por voz para el ordenador:
  coach de vida por voz para llevar tus hábitos, tu dinero y tus tareas. Gratis y sin claves.
  Instrucciones en [jarvis/README.md](jarvis/README.md).
- [`ajedrez/`](ajedrez/README.md) — **Jaque Arena**, app de Android de ajedrez online donde se apuestan monedas
  virtuales y la casa se lleva una comisión. Incluye servidor, app y guía para publicarla en Google Play.
